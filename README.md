# connwatch

Наблюдение за своим Mac с момента запуска. В терминал печатаются только новые уникальные IP исходящих TCP-соединений. По ключу `-o` в файл пишутся пары имени и адреса и отдельно помечаются прямые обращения к IP.

```bash
chmod +x connwatch
./connwatch
./connwatch -o ~/fqdn.txt
```

Скрипт сам запрашивает пароль администратора: захват пакетов на macOS открывается через BPF. Promiscuous mode выключен. Слушаются поднятые интерфейсы `en*`, `bridge*` и туннели `utun*` (VPN): на `pktap` Apple не собирает BPF-фильтр. Новый интерфейс подхватывается в течение пары секунд. Чужой трафик в сети не читается.

Останов: Ctrl-C.

## Что попадает в вывод

- Столбец IP: адрес назначения TCP-сегмента с флагом SYN и без ACK. Повтор того же адреса не печатается. Соединения, открытые до запуска, не показываются.
- Файл `-o`: три поля через TAB. Файл очищается при старте, права `600`.
  - `dns`, FQDN, IP — адрес из ответа DNS на это имя. У одного имени несколько строк, если в ответе несколько A или AAAA.
  - `direct`, `-`, IP — исходящий TCP к адресу, которого не было в увиденном ответе DNS. Если ответ приходит позже, строка `direct` заменяется парами `dns`.

## Ограничения

- Loopback и multicast не печатаются.
- UDP и QUIC без соседнего TCP в столбец IP не входят.
- Через HTTP-прокси в столбце виден адрес прокси. Если этот адрес не пришёл в ответе DNS, в файле он помечается как `direct`, а имена сайтов остаются отдельными строками `dns`.
- DoH и DoT не раскрывают имя: TCP-адрес такого соединения помечается как `direct`. Туннель VPN может не попасть в список, если его интерфейс не поднялся.
- Проверка разбора без захвата: `connwatch --check`. Повтор строк tcpdump со stdin: `connwatch --parse -o файл` при переменных `OUTBOUND_ONLY` и `LOCAL_FILE`.

## Требования и проверка

macOS со штатными Bash, awk, tcpdump, ifconfig и sudo. Дополнительные пакеты не нужны. Проверка парсера не требует sudo и не запускает захват:

```bash
bash -n connwatch
./connwatch --check
```

Успешная проверка выводит `ok`. Выгрузки содержат сетевые адреса и имена; храните их вне репозитория. Для локальных результатов предусмотрен игнорируемый каталог `output/`.
